Turn AI agent QA runs into shareable slideshows.

Your agent drives the browser. qagent captures the moments that matter and ships you back a single URL anyone can watch. Built for founders, operators, and engineers who want their agents to leave receipts.

View on GitHub How it works 
pip install qagent
qagent install-skill

Or run with no install: uvx qagent --help

How it works

qagent is an MCP server, a CLI, and a bundled agent skill. Three steps, one shareable artifact.

1

Install

pip install qagent, then qagent install-skill to teach your agent how to write good captions and structure a run.

2

Run a QA

Ask your agent to QA a flow. It drives the browser, screenshots the moments that matter, captions each one, and writes a summary at the end.

3

Share

You get a slideshow URL. Drop it in Slack, paste it in a PR, send it to a teammate. Anyone can watch the whole run with no install.
