# AgentClip Positioning

This note is the short, load-bearing positioning document for AgentClip. When writing copy, shaping the home page, curating gallery clips, or deciding which examples best represent the product, start here.

## Core idea

AgentClip helps a coding agent create a video that is easy to share immediately.

That is the wedge:

1. `video`
2. `agent-created`
3. `instantly shareable`

If product framing drifts away from any of those three, it is probably drifting away from what makes AgentClip distinct.

## The problem

People who work with coding agents often get useful output, but the output is awkward to share.

Typical agent output looks like:

- long chat transcripts
- logs
- diffs
- screenshots
- pasted notes
- rough summaries

Those artifacts are often good enough for the person who ran the agent, but not good enough for everyone else. They are hard to skim, hard to trust quickly, and hard to forward cleanly.

The communication problem shows up in a few recurring situations:

- a feature changed and someone needs to see what changed
- a bug was found and someone needs to reproduce it
- an agent investigated a tool, workflow, or public dataset and needs to explain the takeaway
- an agent tested or verified something and needs to provide proof

The real pain is not only "the agent did work." The pain is "the output is not yet in a form that is easy to watch and easy to share."

## Who has this problem

The primary user is someone who interacts with coding agents often.

That usually includes:

- AI engineers
- technical founders
- PMs who use coding agents heavily
- product-minded engineers
- technical operators
- developer advocates

The product should not over-specify the audience in top-level marketing copy. It is enough to stay anchored on `coding agents` and the work around them.

The important split is:

- **creator:** the person running or orchestrating the agent
- **viewer:** anyone who needs to understand the result quickly

The viewer may be technical or non-technical. The constant is that the creator needs a cleaner communication artifact than a transcript or a diff.

## Why AgentClip's solution fits this problem

AgentClip does not merely summarize the work. It turns agent output into a video artifact.

That is a better match for this problem because video is:

- faster to understand than a transcript
- easier to share than a notebook of screenshots
- better at showing sequence, motion, and context
- easier to forward in Slack, PRs, release notes, docs, or social posts

The solution only works if the video is also:

### 1. Video

AgentClip is not just a summary, transcript, or static report. The core artifact is a video walkthrough.

- The output should feel watchable, not merely readable.
- Home-page copy should say `video` explicitly when possible.
- Gallery examples should prove that video is the communication layer, not an afterthought.

### 2. Agent-created

The point is not only that a human can record a walkthrough. The point is that a coding agent can create it.

- The agent may have built something, tested something, investigated something, or verified something.
- Do not narrow the product to "the agent coded this."
- The common thread is that the agent produced something worth showing clearly.

### 3. Instantly shareable

The video should be easy to send the moment the agent finishes.

- A clip should behave like a shareable artifact, not a heavyweight media workflow.
- The "send this right away" feeling matters as much as the recording itself.
- Favor examples that end in a public URL or an immediately usable artifact.

## Positioning consequences

This positioning broadens the valid example set, but keeps the user sharp.

AgentClip is not only for:

- feature demos
- release notes
- PR walkthroughs

It is also naturally for:

- tool guides
- bug repros
- public-data investigations
- performance and security checks
- "how to use this tool" videos

The common denominator is not that the agent wrote code. The common denominator is that the agent produced output worth turning into a video.

## Branding and copy implications

### What the brand should emphasize

Branding should keep repeating the same three truths:

- this is a `video`
- the `agent` can create it
- it is `easy to share right away`

If a headline or subhead sounds like generic documentation, generic summaries, or generic screen recording, it is too weak.

### What the brand should avoid

Avoid copy that implies:

- the product is mainly a screen recorder
- the output is mainly text or summaries
- the agent always coded the thing being shown
- the product is only for non-technical stakeholders

Those framings are too narrow or too generic.

## Messaging guidance

### Good direction

Lead with the format and the speed of sharing.

Good phrases:

- `shareable video`
- `video walkthrough`
- `narrated video`
- `create a video instantly`
- `show what the agent did`

### Weaker direction

These are weaker if used alone in hero copy:

- `finding`
- `artifact`
- `summary`
- `documentation`
- `screen recording`

They can be useful secondary words, but they should not lead the product story.

## Recommended home-page framing

At the top of the page, keep the story simple:

- the coding agent creates a video
- the video is shareable immediately

Recommended direction:

- headline should say `video`
- subhead can widen the use cases
- gallery can show the range: walkthroughs, guides, bug repros, tool explainers, investigations

### Example headline direction

- `Your coding agent now creates shareable video walkthroughs.`

### Example subhead direction

- `Turn any agent output into a shareable video walkthrough, guide, or bug repro.`

These are examples, not hard requirements. The important thing is that `video`, `agent-created`, and `instantly shareable` stay visible.

## Gallery guidance

Gallery curation should prove range without losing coherence.

Strong categories:

- feature walkthroughs
- guides
- bug repros
- public-tool investigations
- research or verification clips

The gallery should show that AgentClip is the communication layer for agent work, not only the documentation layer for code changes.

## Shortcut

If copy or product framing drifts, come back to this:

- video
- agent-created
- instantly shareable

AgentClip is the fast, shareable video layer for agent output.
