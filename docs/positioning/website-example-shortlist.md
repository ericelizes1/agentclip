# Website Example Shortlist

These are the five example clips the public site should feature first. The goal is not to show every possible use case. The goal is to show repeatable, useful, low-friction clips that make AgentClip's video format feel obvious.

## 1. Cloudflare Radar Data Explorer

- **Suggested title:** `Guide: How to inspect internet traffic with Cloudflare Radar`
- **Use case:** Show how an agent can explain a public internet trend or traffic shift.
- **On-screen flow:** Open Radar, switch country or category views, compare time ranges, highlight one meaningful chart.
- **Why it belongs:** It is public, visually strong, immediately useful, and proves that AgentClip is not limited to shipped code.
- **Slot:** Hero or top gallery candidate.

## 2. Cloudflare Radar URL Scanner

- **Suggested title:** `Guide: How to investigate a URL before your team clicks it`
- **Use case:** Show how an agent can triage a suspicious or unknown link.
- **On-screen flow:** Paste a URL, run the scan, show verdict, request chain, and report details.
- **Why it belongs:** Strong security angle, obvious input/output, easy to understand quickly.
- **Slot:** Gallery.

## 3. Google Trends

- **Suggested title:** `Guide: How to see if an AI tool is actually trending`
- **Use case:** Show how an agent can validate whether an AI tool has real demand.
- **On-screen flow:** Compare tools by search interest, switch time window, switch geography, highlight the takeaway.
- **Why it belongs:** Public, repeatable, useful, and highly shareable for AI-heavy audiences.
- **Slot:** Gallery.

## 4. urlscan.io

- **Suggested title:** `Guide: How to inspect what a website loads behind the scenes`
- **Use case:** Show how an agent can inspect a site before trusting it or researching a competitor.
- **On-screen flow:** Submit a URL, open the screenshot, show domains, redirects, and third-party requests.
- **Why it belongs:** Clear investigation story, strong visual evidence, useful for both research and security framing.
- **Slot:** Gallery.

## 5. PageSpeed Insights

- **Suggested title:** `Guide: How to check if a site is actually fast`
- **Use case:** Show how an agent can verify performance claims on a landing page or product site.
- **On-screen flow:** Paste a URL, show mobile score, show Core Web Vitals, highlight the biggest issue.
- **Why it belongs:** Familiar, credible, useful, and immediately legible to broad audiences.
- **Slot:** Gallery.

## Why these five

These examples were chosen because they are:

- public or low-friction
- useful without a lot of setup
- easy to understand on first watch
- easy to repeat later for more content
- strong proof that AgentClip is a video communication layer for agent work

They also widen the visible category beyond PRs and releases without making the product feel vague.
