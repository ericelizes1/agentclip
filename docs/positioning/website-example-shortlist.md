# Website Example Shortlist

These are the five example clips the public site should feature first. The goal is not to show every possible use case. The goal is to show repeatable, useful, low-friction clips that make AgentClip's video format feel obvious.

## Final selection

- **Hero:** Cloudflare Radar Data Explorer
- **Gallery 1:** Google Trends
- **Gallery 2:** OpenRouter Rankings
- **Gallery 3:** urlscan.io
- **Gallery 4:** PageSpeed Insights

These five were chosen because they are:

- public or low-friction
- useful without a lot of setup
- easy to understand on first watch
- easy to repeat later for more content
- strong proof that AgentClip is a video communication layer for agent work

They also widen the visible category beyond PRs and releases without making the product feel vague.

## 1. Cloudflare Radar Data Explorer

- **Final title:** `Guide: How to inspect internet traffic with Cloudflare Radar`
- **Use case:** Show how an agent can explain a public internet trend or traffic shift.
- **Opening frame:** Cloudflare Radar already open on a meaningful country or category view.
- **What the clip shows:** The agent switches views, compares time ranges, narrows to one chart, and explains what changed and why it matters.
- **Exact capture flow:**
  1. Open Radar on a useful view, not the home page.
  2. Show the chart that matters first.
  3. Switch one filter or geography.
  4. Compare the trend window.
  5. Land on the final chart and explain the takeaway.
- **What the agent is actually doing:** Investigating a public signal and turning it into a watchable explanation.
- **Why it is strong:** It is public, visually strong, immediately useful, and clearly not just a coding demo.
- **Why it is hero-worthy:** It communicates the broadest version of the product promise: an agent used a real tool, found something useful, and handed back a video someone can send immediately.
- **Suggested takeaway:** `Cloudflare Radar lets an agent turn internet-scale traffic data into a quick, shareable explanation.`
- **Slot:** Hero.

### First recording brief

- **Goal:** Record the strongest first homepage hero clip for AgentClip using a public, high-signal tool and a clearly legible “agent investigated something useful” story.
- **Runtime target:** `35-55 seconds`
- **Recording type:** `guide`
- **Audience:** technical recruiter, AI engineer, product-minded builder
- **What the clip should prove:** an agent can use a real public tool, find a useful signal, and hand back a narrated, shareable video instead of a transcript.

#### Exact headline + metadata

- **Clip title:** `Guide: How to inspect internet traffic with Cloudflare Radar`
- **One-line summary:** `An agent uses Cloudflare Radar to explain a real internet traffic shift in a shareable video.`
- **End takeaway:** `Cloudflare Radar lets an agent turn internet-scale traffic data into a quick, shareable explanation.`

#### Opening setup

- Open Cloudflare Radar to a view that is already interesting.
- Do **not** start on the generic home page if a more specific chart is available.
- Prefer a comparison that is easy to understand without narration-heavy context:
  - country-level traffic change
  - category traffic shift
  - AI / developer-tool adjacent trend if one exists

#### Exact capture flow

1. **Start on the chart that matters**
   Show one clean Radar view immediately so the first frame is useful, not setup.
2. **Change one meaningful dimension**
   Switch geography, category, or filter once so the viewer sees the agent actively investigating.
3. **Change the time window once**
   Use a single time-range change to reveal whether the spike or shift is temporary or sustained.
4. **Hold on the best chart**
   Pause on the clearest final chart long enough for the viewer to read it.
5. **End on the takeaway**
   Let the narration land one specific conclusion instead of ending mid-exploration.

#### Slide-by-slide caption draft

Use these as starting points, then tighten to whatever the actual chart shows.

1. `Opened Cloudflare Radar on a live traffic view so we can start with the signal, not the dashboard.`
2. `Switched the comparison once to see whether this traffic pattern holds across another geography or category.`
3. `Changed the time range to check whether this is a short spike or a more durable shift.`
4. `Held on the clearest chart once the pattern was obvious. This is the frame the viewer should actually remember.`
5. `Ended on the takeaway: Cloudflare Radar gives an agent a fast way to explain a real internet trend in a video someone can immediately share.`

#### Narration script

Use this as the default spoken script, then swap in the actual geography, category, or traffic signal once the final chart is chosen.

1. `Opened Cloudflare Radar on a live traffic view so we can start with the signal instead of the dashboard.`
2. `I changed one comparison to see whether this traffic pattern holds across another geography or category.`
3. `Then I changed the time range once to check whether this is a short spike or a more durable shift.`
4. `At this point the pattern is clear, so this is the chart I would actually send to someone else.`
5. `That is the useful part: an agent can turn a public internet trend into a narrated, shareable explanation instead of a transcript.`

#### Tighter alt script

Use this version if the final clip needs to land closer to `30-40 seconds`.

1. `Started on the chart that matters so we can skip the dashboard tour.`
2. `Changed one comparison to see whether the same pattern holds elsewhere.`
3. `Changed the time range once to tell the difference between a spike and a shift.`
4. `Held on the clearest chart once the result was obvious.`
5. `Cloudflare Radar gives an agent a fast way to explain a real traffic trend in a video someone can share immediately.`

#### Recording notes

- Keep cursor movement intentional; do not wander.
- One filter change is good. Three is too many.
- Favor legibility over exploration depth.
- If the chart needs a long explanation, pick a better chart.
- The final frame should be screenshot-worthy on its own.

#### Why this should be the first hero clip

- It is public and low-friction.
- It looks credible immediately.
- It shows judgment, not just clicking.
- It explains why video is better than a transcript.
- It makes AgentClip feel like a communication product for agent work.

## 3. OpenRouter Rankings

- **Why it belongs in the gallery:** It keeps the homepage grounded in modern AI work instead of only web tooling.
- **Suggested takeaway:** `An agent can turn live model-usage rankings into a fast explanation of which models people actually rely on.`
- **Slot:** Gallery.

## 4. urlscan.io

- **Final title:** `Guide: How to inspect what a website loads behind the scenes`
- **Use case:** Show how an agent can inspect a site before trusting it or researching a competitor.
- **Opening frame:** The URL already entered or a completed public scan already open.
- **What the clip shows:** The agent runs or opens a scan, shows the page screenshot, then highlights third-party requests, domains, and redirects.
- **Exact capture flow:**
  1. Enter or open the target scan.
  2. Show the resulting screenshot.
  3. Open network or domain details.
  4. Highlight one surprising external call or redirect.
  5. End on the explanation.
- **What the agent is actually doing:** Investigating what a website actually loads behind the scenes.
- **Why it is strong:** Clear investigation story, strong visual evidence, useful for both research and security framing.
- **Why it belongs in the gallery:** Very good proof of the “agent investigated something useful” story, but a little more technical than the hero.
- **Suggested takeaway:** `An agent can inspect a site’s real network behavior and hand you a video instead of a raw scan report.`
- **Slot:** Gallery.

## 5. PageSpeed Insights

- **Final title:** `Guide: How to check if a site is actually fast`
- **Use case:** Show how an agent can verify performance claims on a landing page or product site.
- **Opening frame:** The URL field and the finished report, with mobile results ready first.
- **What the clip shows:** The agent runs the report, highlights the score, scrolls to Core Web Vitals, and points to the biggest issue or opportunity.
- **Exact capture flow:**
  1. Paste the URL.
  2. Run the report.
  3. Hold on the mobile score.
  4. Scroll to the most useful metric or recommendation.
  5. End on the diagnosis.
- **What the agent is actually doing:** Verifying whether a performance claim holds up.
- **Why it is strong:** Familiar, credible, useful, and immediately legible to broad audiences.
- **Why it belongs in the gallery:** Broadly understandable and high-trust, though less novel visually than Radar.
- **Suggested takeaway:** `An agent can turn a speed report into a short, shareable explanation of what is actually slow.`
- **Slot:** Gallery.
