# What Makes A Great Marketing Walkthrough

This playbook defines what counts as a strong AgentClip example for the website, social posts, and especially X.

## The job of the clip

A strong marketing clip proves one thing fast:

- an agent did something useful
- the result is easier to understand in video form
- the clip is worth sharing immediately

The clip should not need a long preamble. It should make sense on its own.

## What strong clips have in common

The best clips usually have all of these:

- a clear starting point
- one obvious action or investigation
- one visible result
- one takeaway the viewer can repeat
- a shareable ending state, usually a public URL or finished artifact

If the viewer cannot understand the point within the first 5-10 seconds, the clip is probably too weak for marketing.

## Best clip categories

These categories fit AgentClip well:

- **Feature walkthroughs**: show what changed and why it matters
- **Guides**: show how to use a tool or inspect something useful
- **Bug repros**: show the problem clearly and concretely
- **Public-tool investigations**: show findings from public dashboards, scanners, or explorers

These work well because the agent is doing real work and the result becomes legible in video form.

## Best shapes for website and X

### For the website

Website clips should feel durable and representative.

- choose polished tools or surfaces
- prefer clips with broad relevance
- prefer examples that demonstrate the product promise clearly
- avoid examples that require lots of context to appreciate

Good website clips often answer:

- what changed
- what was found
- what was verified
- why the result is useful

### For X

X clips need to resolve faster.

- first frame should name the tool and task
- action should happen quickly
- there should be one concrete takeaway
- the title should sound like `How to X with Y` when possible

Good X clips are practical, not theatrical.

## What to avoid

Weak clips usually have one of these problems:

- empty dashboards
- too much setup before anything happens
- no obvious payoff
- lots of code or logs with no visual result
- enterprise-only workflows that are hard to repeat
- unclear audience value

Avoid examples that only feel interesting if someone already knows the product deeply.

## Clip quality checklist

Before promoting a clip, check:

- Does the first frame make sense?
- Is the tool or workflow obvious?
- Does the result feel useful, not gimmicky?
- Does the clip end in something shareable?
- Would someone want to send this instead of a transcript?

If the answer to any of those is no, tighten the clip or pick a better example.

## Short rule

The best AgentClip marketing examples are:

- useful
- visual
- fast
- repeatable
- instantly shareable
