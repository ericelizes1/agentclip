# What Makes A Great Marketing Walkthrough

This playbook defines what counts as a strong AgentClip example for the website, social posts, and especially X.

## The job of the clip

A strong marketing clip proves one thing fast:

- an agent did something useful
- the result is easier to understand in video form
- the clip is worth sharing immediately

The clip should not need a long preamble. It should make sense on its own.

## The standard

If a clip is strong enough for marketing, it should be possible to answer these three questions quickly:

- What tool or surface is this?
- What useful thing is the agent doing?
- Why is video better than a transcript here?

If the clip cannot answer those quickly, it is not ready.

## What strong clips have in common

The best clips usually have all of these:

- a clear starting point
- one obvious action or investigation
- one visible result
- one takeaway the viewer can repeat
- a shareable ending state, usually a public URL or finished artifact

If the viewer cannot understand the point within the first 5-10 seconds, the clip is probably too weak for marketing.

## Best clip categories

These categories fit AgentClip well:

- **Feature walkthroughs**: show what changed and why it matters
- **Guides**: show how to use a tool or inspect something useful
- **Bug repros**: show the problem clearly and concretely
- **Public-tool investigations**: show findings from public dashboards, scanners, or explorers

These work well because the agent is doing real work and the result becomes legible in video form.

## Best current strategy

For website and X, prefer **public or low-friction tools with obvious input/output** over enterprise dashboards that require seeded business data.

That usually means:

- public data explorers
- public scanners
- public validators
- low-friction tool demos

This is the right shape because it scales. A repeatable content engine needs clips that an agent can make often, not one expensive demo that only works in a carefully prepared enterprise account.

## Best shapes for website and X

### For the website

Website clips should feel durable and representative.

- choose polished tools or surfaces
- prefer clips with broad relevance
- prefer examples that demonstrate the product promise clearly
- avoid examples that require lots of context to appreciate

Good website clips often answer:

- what changed
- what was found
- what was verified
- why the result is useful

### For X

X clips need to resolve faster.

- first frame should name the tool and task
- action should happen quickly
- there should be one concrete takeaway
- the title should sound like `How to X with Y` when possible

Good X clips are practical, not theatrical.

## Recommended clip structure

Most strong clips should follow this sequence:

1. **Name the tool and task immediately**
2. **Show one concrete action**
3. **Reveal one useful result**
4. **End on the artifact or takeaway**

Do not wander. Do not try to teach the entire tool.

## Recommended runtime

- **Website gallery:** roughly 30-75 seconds
- **Hero candidate:** roughly 30-60 seconds
- **X:** roughly 20-45 seconds

Longer clips are allowed, but they usually need tighter editing to stay promotable.

## What to avoid

Weak clips usually have one of these problems:

- empty dashboards
- too much setup before anything happens
- no obvious payoff
- lots of code or logs with no visual result
- enterprise-only workflows that are hard to repeat
- unclear audience value

Avoid examples that only feel interesting if someone already knows the product deeply.

## Hero criteria

A clip is hero-worthy only if it satisfies all of these:

- first frame is legible without context
- the action is visually clear
- the payoff is obvious
- the result feels broadly useful
- the clip makes AgentClip look like a communication product, not a niche dev workflow

If a clip is useful but needs too much explanation, it is a gallery clip, not a hero clip.

## X criteria

A clip is X-worthy if:

- it can be titled as `How to X with Y`
- it teaches one move or one takeaway
- the result is surprising, useful, or validating
- it does not depend on internal company context

The best X clips feel like public utility, not product theater.

## Clip quality checklist

Before promoting a clip, check:

- Does the first frame make sense?
- Is the tool or workflow obvious?
- Does the result feel useful, not gimmicky?
- Does the clip end in something shareable?
- Would someone want to send this instead of a transcript?
- Can the agent do this again without expensive setup?
- Is there a clean title for it?

If the answer to any of those is no, tighten the clip or pick a better example.

## Recording brief template

Every marketed clip should have a short brief with:

- title
- one-sentence use case
- opening frame
- action sequence
- ending frame
- takeaway
- why it is useful
- why it belongs in hero or gallery

If the clip is for X, also include:

- hook
- on-screen first sentence
- one-line post copy

## Short rule

The best AgentClip marketing examples are:

- useful
- visual
- fast
- repeatable
- instantly shareable

And, most importantly, they make it obvious why the agent should hand you a video instead of a transcript.
