# General Intelligence Company — Style Reference

> Architectural Night Sky

**Theme:** light (with dark hero band)
**Live:** https://www.generalintelligencecompany.com

## Description

Sophisticated aesthetic blending an evocative, illustrative DARK hero with a predominantly minimalist, ARCHITECTURAL LIGHT UI. Typography is restrained and elegant — a SERIF for headlines (gravitas) and a clean sans-serif for body. Surfaces layered with subtle translucency and soft, multi-layered shadows for depth without heaviness. Calm authority + advanced technology, articulated through precise achromatic forms punctuated by a singular cool blue accent for interactive elements.

## Typography

**PPMondwest** (SERIF — "gravitas")
- Weights: 400, 500
- Sizes: 40, 48, 54px (display only)
- Letter spacing: -0.02em

**af** (sans-serif — UI workhorse)
- Weights: 400, 500, 600, 700
- Sizes: 13, 15, 16, 18px
- Letter spacing: -0.012em / -0.010em

## Spacing & Shape

- Base unit: 4px, **density: comfortable**
- Section gap: 32px, card padding: 16px, element gap: 8px
- **Border radius is variable per element:**
  - buttons: 4px
  - navItemsSmall: 8px
  - cardsSmall: 12px
  - cardsMedium: 16px
  - cardsLarge: 24px
  - **nav: 50.496px (highly rounded)**

**Shadows (multi-layered, soft):**
- subtle-2: `rgba(0,0,0,0.08) 0 1px 1px, rgba(0,0,0,0.08) 0 4px 5px`
- sm: `rgba(0,0,0,0.15) 0 2px 6px`

## Key Takeaway for AgentClip

GIC's bones:
- Dark dramatic hero (illustrated cityscape) → light editorial body
- Serif (PPMondwest) for ALL display headlines
- Single blue accent used SPARINGLY (not on backgrounds)
- Multi-layered soft shadows give depth without heaviness
- Rounded nav (50px+) is signature
- Translucent overlay cards on hero (atmospheric depth)
