HOW IT WORKS

Three steps. No accounts. No tracking.

Install once, then your agent can post clips from any QA run.

01 / install

pip install

pip install agentclip. First time your agent uses it, AgentClip wires up the skill and browser drivers automatically.

02 / run

Ask your agent to QA

Point it at any flow. The agent drives the browser and captures the meaningful moments in active voice.

03 / share

Send the URL

One shareable URL. Drop it in Slack, paste it in a PR, send it cold to a recruiter. No login.
