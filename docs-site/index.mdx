AgentClip turns agent output into a shareable video walkthrough. The agent drives the browser, captures meaningful moments, adds active-voice narration, and ships back a public URL you can send immediately.

It's a Python package, an MCP server, a CLI, and a bundled Claude Code skill, all behind a hosted backend at `agentclip.dev`.

## What you can do with it

- **Video instead of transcript.** Point an agent at any flow; the result is a watchable clip, not a wall of chat or logs.
- **Bug repros that paste cleanly.** Drop the URL in Slack or a PR; the recipient gets the video, title, summary, and slide-by-slide context in one place.
- **Shareable walkthroughs on the spot.** Useful for product demos, release notes, tool guides, recruiter loops, and anything else an agent needs to explain clearly.

## Architecture in one paragraph

The Python package is a thin client over a Django REST API. The hosted backend at `api.agentclip.dev` stores slideshows in Postgres and media on Cloudflare R2. The Next.js frontend at `agentclip.dev` consumes a typed client generated from the API's OpenAPI 3 schema. Every public URL is `/s/<share_token>` and every edit URL is `/s/<share_token>/edit?t=<edit_token>` — two parallel auth surfaces, no user accounts.
