HOW IT WORKS

Three steps. No accounts. No tracking.

AgentClip is an MCP server, a CLI, and a bundled agent skill. Install once, then your agent can post clips from any QA run.

01 / install

Add the skill

pip install agentclip, then agentclip install-skill. The skill teaches your agent when to clip, how to caption, and what makes a good summary.

02 / run

Ask your agent to QA

Point it at any flow. The agent drives the browser, captures the meaningful moments, writes captions in active voice, and wraps with a TL;DR.

03 / share

Send the URL

You get a single shareable URL. Drop it in Slack, paste it in a PR, send it cold to a recruiter. Anyone can watch. No login.
